# أتعلم القراءة — النسخة 4

## أولاً: ربط بيانات الطلاب بحسابك (مرة واحدة، 5 دقائق)
1. افتح **Google Sheets** وأنشئ ملف جديد (اسمه مثلاً «طلاب القراءة»).
2. من القائمة: **Extensions ← Apps Script** وامسح الكود الموجود والصق محتوى ملف `Code.gs`.
3. غيّر السطر `TEACHER_KEY` لرمز تختاره (ده **رمز المعلم**، ومتشاركوش مع حد).
4. اضغط **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   ثم Deploy ووافق على الصلاحيات (هيحذّرك جوجل لأن الكود جديد: Advanced ← Go to project).
5. انسخ رابط الـ Web app (ينتهي بـ `/exec`).

## ثانياً: نشر التطبيق
1. ارفع مجلد `pwa` على **app.netlify.com/drop** (أو GitHub Pages). هتاخد رابط HTTPS.
2. افتح الرابط على جهازك ← ⚙️ الإعدادات ← **🔒 قسم المعلم** ← أدخل رمز المعلم.
   - أول مرة بدون رابط مزامنة: التطبيق هيطلب منك تختار رمز محلي. بعد ربط الرابط الرمز الصحيح هو `TEACHER_KEY`.
3. الصق رابط الـ `/exec` في خانة «رابط المزامنة» واضغط **حفظ**.
4. اضغط **🔗 نسخ رابط الطلاب** وابعته للطلاب/أولياء الأمور. الرابط فيه إعداد المزامنة تلقائياً.

## ثالثاً: متابعة الطلاب
- أي طالب يفتح الرابط ويكتب اسمه، بياناته بتتبعت تلقائياً بعد كل نشاط وتظهر عندك في:
  - **تطبيق**: الصفحة الرئيسية ← ⚙️ ← قسم المعلم ← **👨‍🏫 لوحة كل الطلاب** (أو زر «لوحة المعلم» في شاشة اختيار الطالب).
  - **Google Sheet** مباشرة: صفحة `students`.
- من لوحة المعلم: تقرير كل طالب، رسم بياني، خطة مقترحة، تنزيل Excel، طباعة PDF، وحذف طالب.

## ملاحظات خصوصية مهمة
- البيانات (الاسم والصف والتقدم) بتتخزن في Google Sheet بتاعك أنت. يفضّل استخدام **الاسم الأول أو كود** بدل الاسم الكامل، وخد موافقة المدرسة/الأهل حسب سياستكم.
- كل جهاز يشوف الطلاب المسجّلين عليه هو بس. التقارير والإعدادات الحساسة مقفولة برمز المعلم.
- الرابط اللي بيتبعت للطلاب فيه رابط المزامنة؛ اللي معاه الرابط يقدر يضيف بيانات لكن **ما يقدرش يقرأ** بيانات الطلاب بدون رمز المعلم.

## تحويله لـ APK
افتح pwabuilder.com وحط رابط التطبيق ← Package for stores ← Android ← Generate. أو ثبّته مباشرة من Chrome (⋮ ← تثبيت التطبيق).
